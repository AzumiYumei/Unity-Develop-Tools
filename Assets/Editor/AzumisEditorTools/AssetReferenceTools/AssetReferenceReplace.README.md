# 资源引用查找与替换

扫描目标资源在普通资源、Prefab、Scene 和 Importer 设置中的对象引用，并替换或清空指定引用。结果列出来源路径、所属对象、属性路径和命中目标。

## 入口与输入

- 菜单：`Tools/Azumi/资源工具/资源引用查找与替换`。
- 脚本：[AssetReferenceReplaceWindow.cs](Editor/AssetReferenceReplaceWindow.cs)。
- 输入：目标资源、可选替换资源、可选扫描目录和 Importer 引用开关。

## 使用步骤

1. 指定目标资源，需要替换时填写新的资源；选择扫描目录并检查 Importer 引用开关。
2. 点击“扫描引用”匹配目标；需要把目标内部引用的资源一起匹配时点击“扫描目标及内部引用”。
3. 检查目标匹配集合和结果中的来源、属性路径，使用定位按钮核对。
4. 按需执行“单独替换引用”“单独删除引用”或“批量替换引用”。删除是清空引用字段，不是删除资源文件。
5. 重新扫描确认剩余引用。

## 结果与限制

- 替换会写回资源、Prefab、场景或 Importer；新资源需适合原字段类型，以执行反馈为准。
- 内部引用扫描会扩大匹配集合，执行前检查集合以避免连带替换。
- 基于序列化对象引用，不能完整识别字符串路径、GUID 文本或动态加载。
- 包含不记录 Undo 的写入路径，不应依赖一次撤销恢复全部操作，批量处理前保留版本记录。
