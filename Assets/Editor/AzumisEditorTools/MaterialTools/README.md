# 材质工具

本目录提供四个独立窗口。

| 工具 | 文档 |
| --- | --- |
| FBX 材质映射与预制件材质替换 | [按名称匹配和替换](FbxMaterialRemap.README.md) |
| 批量材质属性赋值 | [统一设置属性](MaterialPropertyBatchSetter.README.md) |
| 材质烘焙成纹理 | [预览与 PNG 导出](MaterialToTextureBaker.README.md) |
| 材质无效属性清理 | [扫描旧属性残留](MaterialUnusedPropertyCleaner.README.md) |
