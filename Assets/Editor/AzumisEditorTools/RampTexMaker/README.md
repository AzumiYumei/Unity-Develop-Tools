# Ramp Tex 生成器

编辑颜色渐变并生成 Ramp PNG，可对照参考 Ramp 纹理，导出后绑定到材质，还可自动覆盖材质当前绑定的纹理资源。

## 入口

- 菜单：`Tools/Azumi/纹理生成与修改/Ramp Tex 生成器`。
- 脚本：[RampGeneratorWindow.cs](Editor/RampGeneratorWindow.cs)。

## 使用步骤

1. 设置渐变方向与纹理尺寸，编辑“渐变颜色”，在 Gradient 中选择适合的平滑或固定渐变模式。
2. 可指定“参考 Ramp Texture”，调整平铺朝向、反转和预览高度，对照上方参考与下方生成预览。
3. 指定参考图时，生成尺寸会跟随参考纹理；不使用参考图时可自行设置尺寸。
4. 可指定“目标材质资源”和内部纹理属性名，让导出结果自动赋值。
5. 点击“导出渐变纹理”，选择 PNG 保存位置，检查生成贴图和材质。

## 输出与限制

- 输出 PNG。导入参数与材质属性应符合项目 Shader 的采样用途。
- 参考图用于对照预览，不自动反向还原渐变关键点。
- 材质不包含指定属性时不会自动赋值，应填写内部属性名而非 Inspector 显示名。
- “自动覆盖绑定纹理资源”开启后，编辑渐变可写入当前绑定的纹理文件。只需预览时关闭此选项，避免改动共享纹理；覆盖前保留版本记录。
