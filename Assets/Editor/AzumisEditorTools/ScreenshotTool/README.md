# 截图与录屏工具

提供 Game 视图截图、指定相机截图、ffmpeg 相机录屏、相机轨迹采样与回放，以及闭合机位路径运镜。

## 入口与依赖

- 菜单：`Tools/Azumi/截图工具`。
- 窗口：[ScreenshotToolWindow.cs](Editor/ScreenshotToolWindow.cs)。
- 配套：[CameraTrajectoryPreset.cs](Editor/CameraTrajectoryPreset.cs)、[CameraRigDriver.cs](Editor/CameraRigDriver.cs)。
- 截图不需要 ffmpeg；录屏需要配置 ffmpeg 可执行文件及 H.264 编码能力。

## 截图

1. 设置项目根目录下的输出目录、文件名前缀和完成后打开目录选项。
2. Game 视图截图设置放大倍数（1～4），点击“截取 Game 视图”。
3. 相机截图指定相机和输出宽高，点击“截取目标相机”。未指定时回退到 Main Camera，确保场景中有可用相机。

截图输出 PNG。相机截图来自独立 RenderTexture，不依赖 Game 视图尺寸；Game 截图遵循 Game 视图捕获方式。

## 相机录屏与轨迹回放

1. 配置 ffmpeg 路径、录制时长、延迟、输出宽高。当前录制帧率固定为 **60 fps**，宽高调整为正偶数。
2. 使用 `Trajectory` 模式，点击“开始录制相机”。需要保存运镜时启用“录制时记录轨迹”。
3. 录制结束后点击“保存最近录制轨迹预设”，保存 `.asset`。
4. 将有效预设放入“回放预设”，点击“回放轨迹并录制”。有效预设需要至少两个关键帧且时长大于 0。
5. 可取消延迟录制或停止录制，窗口显示进度和最近输出。

轨迹包含位置、旋转、视场角/正交参数。回放使用离线逐帧采集，处理耗时可能长于视频时长；预设只保存相机数据，不保存整个场景动画与随机状态。

## 机位运镜

1. 切换到 `Rig` 模式，添加至少两个有效 Transform 机位并指定 LookAt 目标。
2. 设置平滑时间和最大速度，路径按机位顺序走完并回到起点。
3. 编辑模式下点击“预览机位运动”核对路径；录制时使用“开始录制相机”。
4. 机位回到起点时提前结束，录制时长作为最大上限。此模式不使用轨迹回放按钮。

## 输出与限制

- 视频为无音频 H.264 MP4，采集目标 Camera 的独立渲染结果，不捕获编辑器面板。
- 普通实时录制遇到采集掉帧时，仍以 60 fps 编码，成片可能短于配置时长。需要严格固定帧数和自定义帧率时使用 [Pure Screen Recorder](../PureScreenRecorder/README.md)。
- 轨迹和机位模式会驱动相机，避免同时运行其他相机控制脚本。停止后工具恢复相关相机状态。
- 目录内 `Screenshot_Trajectory_*.asset` 是已有轨迹，可供回放，适用效果取决于场景。
- 配套轨迹类型位于 Editor 目录，只面向编辑器工作流；不要直接依赖其进行 Player 运行时回放。
