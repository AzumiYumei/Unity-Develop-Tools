# 未使用资源查找

检查指定目录中的资源是否被扫描范围内的其他资源直接依赖，列出没有发现引用的候选项，并提供定位与删除操作。

## 入口与输入

- 菜单：`Tools/Azumi/资源工具/未使用资源查找`。
- 脚本：[UnusedAssetFinderWindow.cs](Editor/UnusedAssetFinderWindow.cs)。
- “待检查目录”决定候选资源；“引用扫描范围”决定查找引用的来源，留空时扫描 `Assets`。

## 使用步骤

1. 指定待检查目录，选择引用扫描范围。通常使用整个 `Assets`，避免遗漏目录外的引用。
2. 点击“扫描未使用资源”，查看候选数量、来源资源数和结果。
3. 用“定位资源”检查每项实际用途。
4. 确认后可“删除该资源”或“删除全部结果”；按对话框确认后执行。
5. 删除后检查场景、Prefab、运行时加载及版本控制差异。

## 判断方式与限制

- 使用 `AssetDatabase.GetDependencies(path, false)` 检查来源资源的直接依赖，排除自引用；候选中排除脚本、程序集定义等类别。
- 不以构建入口的可达性为标准：一个本身未使用的资源引用另一个资源，也会使后者不出现在结果中；循环依赖也可能保留。
- `Resources.Load`、Addressables 字符串键、自定义路径加载、远程配置等不一定被识别。结果是候选清单，不是删除安全性的证明。
- 删除使用 `AssetDatabase.DeleteAsset` 实际移除资源，不是移入回收站，不提供可靠的 Undo 恢复。保留版本记录后再删除。
